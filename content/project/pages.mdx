## Project Overview

A fully static portfolio website built with **Next.js App Router**, showcasing projects, blog posts, and personal info. Deployed to GitHub Pages with zero-cost hosting and automatic CI/CD.

```tsx
// Homepage Bento Grid Component
import { BentoGrid } from '@/components/bento/BentoGrid'
import { Github } from '@/components/bento/Github'
import { Youtube } from '@/components/bento/Youtube'
import { FlipNumber } from '@/components/FlipNumber'

export default function HomePage() {
  return (
    <BentoGrid>
      <Github />
      <Youtube />
      <FlipNumber value={42} label="Projects" />
      {/* Other bento cards */}
    </BentoGrid>
  )
}
```

Content is MDX-driven (`content/blog`, `content/project`) and processed by Contentlayer for type-safe rendering. Perfect for developers who want a professional site without server management.

## Deployment Setup

1. **Static Export**: `next.config.js` enables `output: 'export'`
2. **Build Workflow**: `.github/workflows/nextjs.yml` runs `next build` and pushes to `gh-pages`
3. **Custom Domain**: Optional via GitHub Pages settings
4. **Secrets**: API keys in repo secrets (`test-secrets.yml`)

Deploys in under 2 minutes per push to `main`.

```yaml
# .github/workflows/nextjs.yml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: 18
      - run: npm install
      - run: npm run build
      - uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./out
```

## Deployment Guide

### Quick Start Deployment

Deploy this portfolio to GitHub Pages in under 10 minutes:

#### Prerequisites
- GitHub account
- Node.js 18+ installed
- Basic command line knowledge

#### Step 1: Fork and Clone
```bash
# Fork the repository on GitHub, then clone
git clone https://github.com/yourusername/Portfolio.git
cd Portfolio

# Install dependencies
npm install
```

#### Step 2: Configure for Your Use
```bash
# Update package.json with your info
npm pkg set name="your-portfolio-name"
npm pkg set author="Your Name <you@example.com>"

# Update Next.js config for your domain
# next.config.js
const nextConfig = {
  output: 'export',
  images: {
    unoptimized: true,
  },
  // Add your custom domain
  // assetPrefix: 'https://yourdomain.com',
}
```

#### Step 3: Customize Content
```bash
# Replace images in public/ folder
# Update content in content/blog/ and content/project/
# Modify components in app/ to match your style
```

#### Step 4: Deploy to GitHub Pages
```bash
# Commit your changes
git add .
git commit -m "Customize portfolio"
git push origin main

# GitHub Actions will automatically deploy
# Check Actions tab for deployment status
```

### Troubleshooting

#### Common Issues
```bash
# Build fails locally
npm run build  # Test build process

# Images not loading
# Ensure images are in public/ folder
# Use absolute paths: /images/photo.png

# 404 on page refresh
# Add _redirects file for SPA routing
echo "/* /index.html 200" > public/_redirects

# Custom domain not working
# Check CNAME file exists in public/
# Verify DNS settings with domain provider
# Wait up to 24 hours for DNS propagation
```

#### Performance Tips
- Use WebP images in `public/` folder
- Minimize bundle size with code splitting
- Enable compression in `next.config.js`
- Use lazy loading for images and components
